# Starbie KiCad Design Files

PCB schematic and layout files for Starbie.

## Files

- `Starbie.kicad_sch` - Schematic
- `Starbie.kicad_pcb` - PCB layout
- `Starbie.kicad_pro` - Project file
- `Starbie.kicad_prl` - Project local settings
- `Seeed_Studio_XIAO_Series.kicad_sym` - XIAO microcontroller symbol library
- `Display_128x64_096_I2C.kicad_mod` - OLED display footprint
- `XIAO-ESP32-C6-DIP.kicad_mod` - XIAO ESP32-C6 footprint
- `fp-lib-table` - Footprint library table

## Opening the Project

Open `Starbie.kicad_pro` in KiCad 8.0 or later.
