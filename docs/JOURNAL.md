# Project Journal

## Overview

Starbie is a tiny motion-controlled digital pet built as a Half Life 1st week project.

## Development Notes

I started building this project on Half Life, since I was new to this field, I wanted to try a challenge and Half Life found me. Now I am making cool projects with it, starting with Starbie.

At first I did not have an idea how to make it, but thanks to the guide.

When I opened KiCad, I was unsure about using it, but after searching about it, I learned to use it.

First I uploaded Starbie libraries and started building its components although it was hard, I managed to complete it.

The hard part was editing the PCB. I did not know what to do; my work was absolutely complex so I used the guide to lead me all the time.
