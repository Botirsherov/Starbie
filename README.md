## Starbie

A tiny motion-controlled digital pet, basically a desktop Tamagotchi. Totally not a Starboy.

I started building this project on Half Life, since I was new to this field, I wanted to try challenge and Half life found me, now I am making cool projects with it, starting with Starbie.

AT first I do not have an idea how to make it, but thanks to guide.
When I opened KiCad, I was unsure about using it, but after searching about it, I learned to use it.
First I uploaded Starbie libraries and started building it's components althought it was hard, I managed to complete it.
The hard part was editing PCB, I do not know what to do, my work was absolutely complex so I used guide to lead me al the time.
